# Cache Hit Test Pairs — ООО «ТехноСфера»

Тест-кейсы для проверки кэша RAG-пайплайна (порог сходства 0.9).
Каждая пара: оригинальный вопрос (хранится в кэше) + перефразировка (новый запрос).
Ожидаемый результат: cache hit, без повторного обращения к RAG.

**Формат:** `Q` — оригинал (в кэше), `A` — перефразировка (новый запрос)
